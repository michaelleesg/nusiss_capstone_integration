Makefile helpers (remember: real TABs on recipe lines)
.PHONY: publish publish-all tag lfs-check

publish:
	@git fetch team
	@git status -sb
	@git push

publish-all:
	@git fetch --all --prune
	@git push team        HEAD:main
	@git push integration HEAD:main || true
	@git push test        HEAD:main || true

tag:
	@if [ -z "$${V}" ]; then echo "Usage: make tag V=0.1.0"; exit 2; fi
	@git tag -a "v$${V}" -m "Release v$${V}"
	@git push team "v$${V}"

lfs-check:
	@git lfs ls-files || true

WSL-Safe Scripting Rules (always apply)

Avoid set -e (or trap it carefully) to prevent closing the WSL window on errors.

Provide both copy-paste blocks and downloadable files when giving scripts.

For Makefiles:

Use real TABs for recipes (not \t or spaces).

Escape single quotes inside single-quoted jq as: '\''

Use ?= for defaults; avoid shell ${...} in recipes that cause $/$$ issues. If needed, pass values via $(VAR).

Use $$ when a literal $ must reach the shell.
